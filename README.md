# BREW — コーヒー抽出ナビ

スマホ片手に「淹れて・計って・記録する」をひとつにまとめた、シングルファイルのコーヒー抽出アプリです。プロのレシピを豆量に合わせて自動換算し、内蔵タイマーで投数をガイドしながら、淹れたあとの味わいまで記録できます。

> 100% クライアントサイド（`index.html` 1 枚）で動作。データはすべてブラウザの `localStorage` に保存され、外部サーバーには一切送信されません。

## 特徴

- **10 種のプロレシピを収録** — 萩原 ／ THE COFFEESHOP、粕谷 ／ 4:6・10投式、ブルーボトルのレシピをまとめて参照。
- **豆量で自動スケーリング** — 基準レシピの注湯量・累計量・氷量を、選んだ豆量に比例して再計算。
- **抽出タイマー** — 円形ダイヤルと投数リストで「いま何 g 注ぐか／次は何秒か」をガイド。経過は実時刻から計算するので、画面を消しても戻ればズレていない。抽出中は画面を消させない（Screen Wake Lock）。
- **投数のアラート** — 注ぐ 3 秒前に予告音、注ぐタイミングで 2 度の音とバイブ、目安時間で 3 度の音。音・バイブは個別に ON/OFF でき設定は記憶される。
- **挽き目記録** — 1〜10 のスライダーでグラインダー設定を記録。
- **落ち切り時間の記録** — タイマー画面のボタンひとつで落ち切り（プレス系は抽出完了）の時刻をスタンプ。レシピの目安との差から「次回は細かく／粗く」を提案し、記録にも残す。押しそびれても記録画面で手入力できる。
- **写真で豆登録** — 豆袋や BEANS LOG カードを撮るだけで登録開始。写真は端末内で長辺 1400px の JPEG に縮小して保存し、一覧のサムネイルをタップで拡大。品種・標高・飲みごろなど入力しきれない情報は写真で見返せる。
- **カードから貼り付け登録** — 「指示文をコピー」→ カードの写真と一緒に Claude へ → 返ってきた JSON（または「名前：〇〇」の行）を貼って「読み込む」で、名前・ロースター・産地・焙煎度・焙煎日・精製・フレーバー・飲みごろ・詳細が一度に埋まる。
- **豆の在庫管理** — ロースター・原産地・焙煎度・焙煎日（焙煎後日数を自動計算）・精製・フレーバーノート・品種などの詳細を登録。使用中／使い切りで管理。
- **飲みごろ表示** — カードの Good Time to Drink（焙煎後 21〜63 日など）を登録すると、焙煎後日数から「あと○日で飲みごろ／飲みごろ／飲みごろ過ぎ」を表示。
- **テイスティング記録** — 酸味・甘み・ボディ・余韻（各 5 段階）、総合★評価、フレーバーメモ、「また淹れたい」フラグを保存。
- **振り返り** — 記録タブの「振り返り」で、レシピごとに回数・★平均・落ち切り平均（目安との差）・挽き目平均と、★が最も高かった回の設定を表示。挽き目×落ち切りを★で色分けした散布図つき。
- **オフライン対応・登録不要** — インストールもアカウントも不要。ブラウザで開くだけ。

## 使い方

1. `index.html` をブラウザで開く（PC・スマホどちらも可）。
2. **淹れる** タブでレシピを選ぶ。
3. **設定** 画面で豆量を調整し、必要なら挽き目・使う豆を選択。レシピが自動換算される。
4. **タイマー開始** → ダイヤルとガイドに沿って抽出。
5. お湯が落ち切ったら **落ち切りを記録** をタップ（タイマーも止まる）。目安との差と挽き目の調整案が出る。
6. **淹れ終わり → 記録** で味わいを評価して保存。
7. **記録** タブで過去の抽出を、**豆** タブで在庫を確認。

豆の登録は **豆** タブ（またはレシピ設定画面）の **📷 写真で登録** から。カメラが開き、撮った写真つきで登録画面に入る。

### ローカルで開く

```bash
git clone https://github.com/slothfront/coffee-log.git
cd coffee-log
# そのままブラウザで開くか、簡易サーバーで配信
python3 -m http.server 8000   # → http://localhost:8000
```

## 技術メモ

- 依存ライブラリなし。HTML / CSS / バニラ JavaScript のみの単一ファイル。
- フォントのみ Google Fonts（Archivo / Space Grotesk）を CDN から読み込み。
- 保存キー：豆は `coffee_beans`、抽出記録は `coffee_brews`（いずれも `localStorage`）。
- 豆の写真は `localStorage`（約5MB上限）を圧迫しないよう、IndexedDB `coffee_media` / オブジェクトストア `photos` に Blob で保存。豆のレコードは写真のキーだけを持つ。
- 写真は保存前に canvas で長辺 1400px・JPEG 品質 0.7 に再エンコード（1枚あたり概ね 100〜300KB）。EXIF の向きは `createImageBitmap` の `imageOrientation:'from-image'` で反映。
- 抽出記録の落ち切りは `drawSec`（秒）／`targetSec`（レシピの目安）／`drawLabel`（落ち切り・抽出完了の別）。レシピ側の `drawdown` フラグでドリップ系かプレス系かを判定。
- タイマーは加算カウントではなく開始時刻との差分。バックグラウンドで `setInterval` が絞られてもズレない。復帰時は `visibilitychange` で即座に追いつき、飛ばされたアラートは「発火済み」にして鳴らさない（2 秒以内のものだけ鳴らす）。
- 通知音は Web Audio（外部ファイルなし）。`navigator.vibrate` はバイブ。設定は `localStorage` の `coffee_alert`。
- 貼り付け登録は JSON を優先し、失敗したら `キー：値` の行として解析。焙煎日は `2026.7.8` 等を `YYYY-MM-DD` に正規化、飲みごろは「21〜63日」から範囲を取り出す。
- データはブラウザ・端末ごとにローカル保存。キャッシュ削除や別端末では引き継がれません。
